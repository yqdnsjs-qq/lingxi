## 六、踩过的坑（铁律，别重犯）

1. **改完代码必须重启**：本机 `restart_server.py`，服务器 `systemctl restart lingxi`。不重启 = 无效。
2. **大表操作必须走索引**：`files` 表 2.4 GB、名字向量占 900 MB。`SELECT * + LIKE`、`SUM(size)`、`GROUP BY kind` 不加索引就是几十秒。
3. **异步接口里不许放阻塞调用**：`store.stats()`、`list_folders()`（内含网络盘 `isdir`）、全表 `GROUP BY`，一律 `run_in_threadpool` 或先给缓存。
4. **uvicorn 的 keep-alive 默认 5 秒**：浏览器会复用已断开的连接，表现是“点一下卡十几秒”。已设 75 秒，别改回去。
5. **前端调 `window.xxx` 前先确认它真挂上去了**：`window.refreshFolders` 就是“调了个空气”，页面永远停在占位文字。
6. **不要用加载时的快照做判断**：`const folders = window.__folders` 会过期且可能不是数组（`(folders || []).find is not a function`）。
7. **仅文件名模式不要按扩展名跳过**：安装包正是用户最想搜到的东西。
8. **路径改写必须停服务**，改完必抽样：`domain: remap_paths.py` 会先验“新路径读得到”才落库。
9. **推库会把服务器路径打回 Windows**：`sync_db.py` 的 `PATH_MAP` 必须覆盖所有共享（**IP 写法与 `\\NAS\` 写法都要有**）。
10. **别让两个同步同时跑**：会抢同一个 `_db_push.db`，日志卡死、库互踩。现在有锁，但别手工绕过去。
11. **`run/` 目录被 .gitignore 忽略**：改了 `run\deploy\*` 不会进仓库，换机器要手动带走。
12. **前端改了要 `rehash_static.py`**，否则页面拿旧 `app.<hash>.js`；给用户的话术永远是“Ctrl + F5”。
13. **FTS5 别用 trigram、也别拿 bm25 排序**（3.5.14 实测）：trigram 三个字以下 0 命中（「报纸」查不到）；bm25 在全命中时要 1.6 秒，比它替代的 LIKE 还慢。文件名通道用「中文逐字 + 英文整词 + 短语 + rowid 倒序取候选 + 本地重排」。
14. **文件名 FTS 有版本号**（`meta.name_fts_fmt`）：改切词规则必须把 `namefts.FORMAT` 加一，否则老索引会被当成有效的（服务不会重建，结果对不上）。
