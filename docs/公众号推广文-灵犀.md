# 灵犀：一个能问、能看图、还能管住"谁能看"的本地知识库

上周三下午，客户在电话里问我：

> "上次那个报价，材料费是怎么折的？"

我知道这份东西存在。可能在去年 11 月的项目文件夹，可能是我自己拉的 Excel，也可能是同事发来的 PDF。

我翻了六分钟，说了句"我回头确认一下发您"。

挂掉电话，我在灵犀里输入：**材料费 折算**。三秒后，那份 Excel 的第 3 个工作表被高亮出来，正好是那几行数字。

**这就是灵犀要解决的那个时刻：你明明有，却说不清它在哪。**

---

## 一、它是什么

> **灵犀是装在你自己的电脑（或你自己的服务器）上的私有知识库。**
> 把散在磁盘里的文档、图片、录音，变成可以**搜**、可以**问**、可以**管**的东西。
> 回答带出处，数据一步不出你的机器。

不是网盘，不是笔记，也不是又一个要你上传资料的 AI 助手。

它更像你资料的**索引员 + 记录员 + 档案管理员**。

## 二、六个标签，六件事（先看全景）

打开就是五个主标签 + 一个设置页，功能不散：

| 标签 | 干什么 | 关键能力 |
|---|---|---|
| 💬 **聊天** | 跟 AI 对话 | 多会话、联网、接自己知识库、接 Dify、传附件、导出 |
| 🔍 **搜索** | 找文件 | 说人话就搜到、能搜图、能预览、能定位、能打开 |
| 📚 **知识库** | 就资料提问 | 只查"知识库"文件夹、回答带引用、追问、传图问 |
| 📁 **文件夹** | 管索引 | 每个文件夹一个模式、排除目录、索引统计、归属 |
| ⚙ **设置** | 调系统 | 服务器与共享 / 模型与系统设置 / 人物命名 / 备份与恢复 |

下面一个一个说。

## 三、🔍 搜索：说人话，找东西

**输入框直接写你要找什么，不用记文件名。**

| 你心里想的 | 你直接打 |
|---|---|
| 去年那份差旅报销的发票 | `去年的差旅报销发票` |
| 讲极光成因的资料 | `极光是怎么形成的` |
| 蓝色圆形的产品图 | `蓝色圆形的产品图` |
| 算个税的脚本 | `计算个人所得税的代码` |

它不比字符，比**意思**。顺序、用词、语序都不影响。

**它还能搜图。**
图片在入库时会被模型"读"一遍，变成可检索的内容——所以你说"蓝色圆形的产品配图""一张表格截图"，它能把符合描述的图捞出来。这是文件名搜索永远做不到的。

**搜到之后，直接能用：**

- **预览**：图片、PDF、音视频直接看；文本和 Office 显示正文，并且**高亮你搜的词**
- **定位文件**：打开资源管理器并选中它，窗口自动置前
- **默认程序打开**：交给 Word / 看图 / 播放器
- **下载一份出来**
- **来源标注**：每条结果都标着它来自哪个文件夹、哪种模式

## 四、📚 知识库：不只是搜，是"问"

搜到之后，你多半还有下一句："那到底怎么说的？"

于是有了**知识库问答**：

- 只查你**明确标了「知识库」**的那几个文件夹（资料归资料，素材归素材，不混）
- 回答**带引用编号**，点开就是原文段落
- 支持**追问**（它记得你上几轮问过什么）
- 支持**传图提问**（比如"这张报表里第三列是什么意思"）
- 回答用哪个模型可以选：本机模型 / 外部 API
- 可以勾 **☁ Dify 一起查**：本地资料标 `[1]`，Dify 资料标 `[D1]`，两套来源分得清清楚楚

```
你：报销上限是多少？
它：一线城市住宿上限 600 元/晚 [1]，交通费据实报销 [2]。
    [1] 差旅管理制度.pdf · 第 3 节
    [2] 报销流程说明.docx · 第 2 段
```

**每句话都能核对**——这是它敢用在工作上的前提。

## 五、💬 聊天：一个"什么都能接"的对话框

这是功能最集中的一个页面：

| 能力 | 说明 |
|---|---|
| **多会话** | 新建、切换、删除，历史都留着 |
| **联网搜索** | 打开后先搜网，回答里标 `[W1] [W2]` |
| **接自己的库** | 勾一下，先在本地资料里找，再回答 |
| **接 Dify** | 同上，公司已有 Dify 也能一起用 |
| **传附件** | 图片直接拖进去问 |
| **导出** | 整个对话导出留档 |
| **选模型** | 本机模型 / 你配的外部 API（含服务器公用、别人共享给你的） |

## 六、📁 文件夹：每个目录可以有自己的"性格"

这点很实用——不是所有资料都值得用同样的代价去索引。

| 文件夹类型 | 推荐模式 | 为什么 |
|---|---|---|
| 文档 / 代码 | **仅文字** | 最快，图片用不上 |
| 产品图 / 截图 | **文字 + 图片** | 可以用"蓝色圆形"找图 |
| 录音 / 会议 | **全模态** | 能按声音内容找 |
| 安装包 / 备份 | **只索引文件名** | 不读内容，秒级完成 |

而且**搜索是统一入口**：不同模式、不同维度的结果混在一起按相关度排序，每条都标注来源模式。

同一页还有：

- **默认排除目录**：`node_modules`、`.git`、缓存目录一次排掉，不用每个文件夹写一遍
- **索引统计**：多少文件、多少片段、占多少空间
- **增量与重建**：新文件自动补，坏了能重建
- **归属**：这个文件夹归谁（多人用时才有意义，见第九节）

## 七、🖼 图片和人物：让"图"也能被找到

图片默认是黑盒——除了文件名，你对它一无所知。灵犀做了两件事把它打开：

### ① 自动打标

入库时用视觉模型读一遍图，写一段描述（"一张会议室白板照片，上面写着预算表"）。
之后你搜"会议室白板预算"，这张图就能被搜到。

**PDF 里的插图也能打标**（单独一个队列，慢慢跑，不影响正常使用）。

### ② 人物命名

人脸自动聚类，把同一个人归到一起，然后**让你给它们起名字**。

我自己的库聚出了 **3,403 个人**——大部分是这些年活动、会议、随手拍里的人。
起完名之后，你可以直接说"找一下某某在某次活动上的照片"。

配套的手动工具也齐：合并相似组、同名去重、补提漏掉的人脸、归类补全。

## 八、🔤 OCR（可选）：扫描件也能读

**不装也能用**——只是 PDF 只能按文件名搜，扫描件里的文字提不出来。

装了之后，扫描件、截图里的正文都能进索引。三个引擎按需选：

| 引擎 | 体积 | 显存 | 适合 |
|---|---|---|---|
| **RapidOCR**（建议先用） | 0.26 GB | 不占（纯 CPU） | 日常扫描件、截图 |
| PP-OCRv6 | 3.8 GB | 要 GPU | 需要文字坐标、更高准确率 |
| MinerU | 11.6 GB | 要 GPU | 结构化 Markdown、表格、自动提图 |

不绑架你的硬盘——不用就不装。

## 九、👥 多人共用：边界写在代码里

一个人用是工具，几个人用就是**制度**。

灵犀可以装在一台服务器上，让家里人、同事一起用：

- **账号与角色**：管理员 / 普通用户，权限不同
- **归属**：每个文件夹有主人，普通用户只看得到自己名下的 + 别人共享给他的
- **共享**：可以给所有人，也可以点名给某几个人
- **🔒 隐私文件夹**：勾上的目录"内容永不出这台机器"——打标强制走本地视觉模型，问答时它的片段一条都不会发给外部模型（**管理员也一样**），本机搜索照常可用
- **自助注册开关**：默认关闭，开了还要你审批
- **自己改名改密码**：不用找管理员

服务器不建库——索引在你那台"建库机"上做，做完**上传**：

- 「服务器连接」里填账号 + 密码，点「**保存并验证**」，会真的登录一次服务器，并显示"你在服务器上是哪位"
- 「上传到服务器」那张卡里**没有**账号密码框：身份只认验证过的那一组，防止有人临时换个身份乱传
- 「我的数据 / 共享给我的」一眼看清哪些是你的、哪些是别人给你的

**边界不该靠自觉。**

## 十、🧠 模型与系统设置：不将就

| 项 | 你能调什么 |
|---|---|
| **运行模式与设置** | 运行设备（auto / cuda / cpu）、精度、**向量维度**（128 最省，256 质量几乎无损）、切块长度等十几项；每项都标明"立即生效"还是"需要重载模型" |
| **显存控制** | 模型占多少显存、什么时候卸载，单独一页 |
| **外部模型** | 多套 API 并存（Ollama / OpenAI 兼容 / llama.cpp），每套单独填地址、模型、Key、请求头；每套可设「谁能用：只有我 / 所有登录用户 / 指定的人」 |
| **Dify 知识库** | 可以接多个库；默认只有自己能用，要共享得自己选人；**密钥永不下发** |
| **图片打标 / PDF 插图打标** | 开关与队列，随时停 |

> 服务器上部署的那台 llama.cpp（没填 Key）算**公共资源**：所有登录用户直接能用，不用自己配。
> 管理员那套带密钥的，只要没共享，别人连名字都看不到。

## 十一、💾 备份与恢复：出事能回去

- **快照**：代码 + 配置 + 关键状态，一键拍一份，带备注
- **异地副本**：快照同步到 NAS / 移动硬盘
- **数据库备份**：增量，秒级完成，服务开着也能备
- **定时增量备份**：本机计划任务 / 服务器 crontab，6 小时一份，自动轮换
- **恢复**：弹文件框点一下，还会自动留一份安全副本

## 十二、我们没妥协的四个地方

功能之外，这几条是我们在很多个"要不要将就"的时刻没将就的：

### ① 数据不出机器

文件和向量都在本地，模型跑你自己的显卡（没独显用 CPU 也能跑）。
不传云端、不要账号、**断网也能搜**。
整个程序就在一个文件夹里：不改注册表、不装系统服务、不动 PATH。
不想要了，删文件夹就干净了——**卸载不需要"卸载程序"**。

### ② 每句话都要能核对

AI 最危险的不是不会，是**一本正经地编**。
所以每次回答都带 `[1] [2]`，点开就是原文。你不信，可以自己去看。

### ③ 不确定就说不知道

库里没有就说没有；证据太弱就说"我只找到这些，可能不够"。
不猜、不圆、不为好看而补充。

### ④ 边界写死在代码里

- 别人的 API 密钥只在服务端用，**不下发给任何账号**
- 管理员没共享的模型，普通用户看不到
- Dify 默认私有，共享要自己一条条选
- 换账号时，浏览器里上一个人的模型配置会被清掉，不留残影

## 十四、谁适合，谁可以先不用

**适合：**

- 电脑里几万份文件，靠记忆和肉眼在找
- 有大量素材（图片、设计稿、截图），想按画面内容找
- 有不能上传云端的敏感资料，但想要智能检索
- 家里或小团队有台常开的机器，想共用资料又不想互相翻

**可以先不用：**

- 只想纯文件名匹配 → Everything 更快更轻
- 文件基本都在网盘里 → 网盘自带搜索可能够用
- 只有 4 GB 内存又没独显 → 能跑，但会慢

## 十五、怎么开始（大概 30 分钟，25 分钟在下载）

```bat
:: 1. 装 Python 3.12（勾选 Add python.exe to PATH）
:: 2. 解压到纯英文路径，比如 D:\lingxi
:: 3. 双击 setup.bat     ← 建环境、装依赖、下模型（约 2 GB）
:: 4. 双击 start.bat     ← 浏览器自动打开
```

四步，不用敲命令。

装完第一件事：**把那几个"每次找东西都要翻半天"的目录加进去**，选个模式，剩下的它自己扫。

**你负责存，它负责记得。**
