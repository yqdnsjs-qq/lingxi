# 人脸识别功能使用说明

> 这是**可选功能**。不开也能正常用文件搜索，开了就能按人物找照片、以图搜人。

## 一、它和文件搜索的关系

| | 能力 |
|---|---|
| **文件搜索**（原有） | 用大白话搜文件内容、文件名；图片可按内容语义搜 |
| **人脸识别**（新增） | 认出"这是谁"，把照片按人归集；给一张照片找人 |
| **混合搜索**（两者合并） | "张三 海边" = 人物筛选 + 语义搜索，结果融合排序 |

混合搜索同时跑四路召回，用 RRF（倒数排名融合）合并：

| 召回通道 | 说明 |
|---|---|
| `语义` | 内容 / 文件名向量 |
| `文件名` | 文件名、路径包含匹配 |
| `人物` | 含指定人物的照片 |
| `人脸` | 以图搜人时的特征比对 |
| `名称命中` | 关键词直接命中文件名（额外加分） |

界面上每条结果右侧的小标签就是**它靠哪一路被召回的**。

## 二、开启步骤

### 1. 确认依赖和权重都在

```
face-lab\libs\                 人脸依赖（facenet-pytorch + torch）
face-lab\models\checkpoints\   人脸权重 20180402-114759-vggface2.pt（约 107 MB）
```

> 这两样是**独立目录**，不装进项目 venv —— 这是刻意的设计。
> 曾经因为往 venv 里装人脸依赖，pip 顺手把 torch/numpy/pillow 一起降级，
> 把正在跑的服务搞挂了。现在彻底隔离，不想要直接删 `face-lab` 即可。

打开搜索页，界面上的「人物」栏会显示状态。如果显示"不可用"，原因会写在旁边。

### 2. 打开开关

```ini
; config.ini
[face]
enabled = yes
```

改完重启服务（`restart.bat`）。

### 3. 把照片文件夹加进索引

在搜索页点「＋ 添加文件夹（可多选）」，选你的照片目录，然后点「增量更新」。

**索引图片时会顺带提取人脸**（每张图约 0.3 秒，有显卡时）。原有的文字文件不受影响。

### 4. 点「重新聚类」

索引完成后，人物栏里点「重新聚类」，程序会把所有人脸按相似度聚成一组一组。

界面会列出「已命名」和「未命名」两组。未命名的就是待你确认的人。

### 5. 给人物命名

**双击**一个未命名的人物卡片，输入名字即可。

- 同一个人被拆成几组 → 每组都填同一个名字（可以合并）
- 佛像 / 雕像 / 海报这类"不是人"的 → 名字里带 `佛像`、`神像`、`手绘`、`海报`
  等词，程序会自动归为「物件」，不计入人物清单
- 拿不准就留空，别猜 —— 填错的名字会污染"人脸中心"，导致后面归类跟着错

## 三、三种用法

### 1. 按人物找照片

人物栏点一个人 → 结果区立刻列出他的所有照片。

### 2. 人物 + 关键词（混合搜索）

```
搜索框输入：  海边
人物栏选中：  张三
→ 结果 = 含张三 且 内容像"海边"的照片
```

上方「人物模式」有两种：

| 模式 | 行为 |
|---|---|
| 只搜这个人（筛选） | 只保留含此人的文件 |
| 优先这个人（不排除别人） | 不排除，但含此人的排前面 |

### 3. 以图搜人

点「🔍 以图搜人：选一张照片」，选一张有这个人的照片：

```
→ 顶部显示「最像：张三  相似度 92.3%」
→ 下面是按人脸相似度排名的所有照片
```

不需要先命名也能用 —— 它直接拿特征和库里所有人脸比对。

## 四、参数（config.ini 的 `[face]` 段）

| 参数 | 默认 | 说明 |
|---|---|---|
| `enabled` | `no` | 总开关 |
| `min_prob` | `0.90` | 检测置信度下限。**别调太低** —— 神像、海报上的人脸置信度往往比真人还高 |
| `min_size` | `60` | 最小人脸边长（像素）。合影里的小脸靠它控制 |
| `assign_threshold` | `0.55` | 归到某个已知人物的相似度门槛 |
| `search_threshold` | `0.45` | 以图搜人的召回门槛，比归类宽松 |
| `cluster_threshold` | `0.65` | 自动聚类成「人物」的阈值 |

**阈值是在 3000+ 张真实人脸上校准过的**：

```
同一个人之间   相似度中位数 0.88
不同人之间     相似度中位数 0.32
```

## 五、聚类方法为什么用 average-linkage

| 方法 | 纯度 | 碎片度 |
|---|---|---|
| complete-linkage | 100% | **2.96**（同一个人被切成 3 份） |
| **average-linkage** | 96.4% | **1.38** |

`complete-linkage` 要求组内**任意两张**都足够像，而同一个人不同年龄段的两张照片
相似度可能只有 0.5~0.6，于是被切开。`average-linkage` 平衡得多。

## 六、已知限制

1. **大幅度年龄跨度**可能仍被拆成多组 —— 手工给同一名字即可合并。
2. **长得像的亲属**可能被并成一组 —— 提高 `cluster_threshold` 让它们先分开。
3. **约 70% 的照片没有人脸**（风景、截图、文档）。人脸是给搜索**加一个维度**，不替代它。
4. **侧倒的老照片**要确认读图时做了 EXIF 摆正（本项目已处理）——
   实测不摆正时，横着存的照片**整批检不出人脸**。
